# Chess Academy Management System

A Java-based system for managing a chess academy, including user authentication, player management, and tournament organization.


</div>

## About

Chess Academy Management System is a Java application built to manage the operations of a chess academy — handling user authentication, player registration, and tournament organization.

## Features

- User authentication (login/registration)
- Player registration and profile management
- Tournament creation and management
- Match scheduling and results tracking
- Player rankings and statistics

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Java |

## Getting Started

### Prerequisites

- Java JDK installed

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Hiruni0213/Chess-Academy-Management-System.git
   ```
2. Navigate into the project folder
   ```bash
   cd Chess-Academy-Management-System
   ```
3. Compile the Java file
   ```bash
   javac ABCChessAcademy_Project1.java
   ```
4. Run the application
   ```bash
   java ABCChessAcademy_Project1
   ```
